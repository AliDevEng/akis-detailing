## 🧭 Project Structure

- `frontend/` → 🌐 Next.js 16 + TypeScript app (active)
- `backend/` → 🛠️ planned future API/backend (coming later)

## ⚡ Quick Start (Frontend)

```bash
cd frontend
npm install
npm run dev
```

Then open 👉 `http://localhost:3000`

If `3000` is busy, Next auto-picks another port (like `3001`) 🔁

## 🧰 Scripts You’ll Use

Run from `frontend/`:

- `npm run dev` → 👨‍💻 local development
- `npm run lint` → 🧹 lint checks (strict)
- `npm run typecheck` → 🔒 TypeScript safety checks
- `npm run format` → 🎨 Prettier formatting
- `npm run format:check` → ✅ formatting validation
- `npm run build` → 📦 production build
- `npm run start` → 🚀 run production build
