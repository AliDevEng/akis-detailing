# 🚗✨ Akis Detailing

> **Premium car care, polished in the garage and on the web.**

A public project for **Akis Detailing**, a modern car-care website built with a responsive React frontend. The frontend is live in this repo today, and the backend is planned for the next chapter.

---

## 🗂️ Repository Structure

```text
akis-detailing/
  frontend/    ⚛️ React frontend app
```

---

## 🌟 Frontend

The frontend is a sleek single-page React application for the Akis Detailing marketing site.

### ✨ Highlights

- 🏠 Home, services, gallery, about, and contact pages
- 📱 Responsive navigation and mobile-friendly layouts
- 🧼 Service and gallery content managed through local data files
- 💬 WhatsApp, phone, Instagram, and TikTok contact entry points
- 🎨 Tailwind CSS styling with custom animation utilities
- ⚡ Production build and smoke test support

### 🛠️ Tech Stack

| Tool | Version | Purpose |
| --- | --- | --- |
| ⚛️ React | 19.2.x | UI framework |
| 🔷 TypeScript | CRA managed | Type-safe app code |
| 🧭 React Router DOM | 6.30.x | Client-side routing |
| 🎨 Tailwind CSS | 3.4.x | Styling |
| 🏗️ react-scripts | 5.0.1 | Create React App tooling |

💡 React Router and Tailwind are pinned to the latest versions that work reliably with the current Create React App setup.

---

## 🚀 Run Locally

```bash
cd frontend
npm install
npm start
```

🌐 The app runs at [http://localhost:3000](http://localhost:3000).

## ✅ Useful Commands
